WINDOWS PROGRAMS
================

Put a Windows program (a file ending in .exe) in this folder, then open "Windows Programs (Bottles)"
from the Start menu and choose Run Executable.

Please read this first. It is short and it is honest.

WHAT USUALLY WORKS
  Small, self-contained programs. Older installers. Utilities written for Windows 7 that never needed
  anything unusual from the computer.

WHAT DOES NOT WORK
  Microsoft Office. Adobe Photoshop and the rest of Creative Cloud. Anything that came with a USB
  licence dongle. Anything that installs its own driver. Most modern games.
  These are not "not yet" — we have no way to make them work and we are not going to pretend otherwise.

WHAT TO DO BEFORE YOU DEPEND ON IT
  Test the exact program you care about, on this computer, doing the exact thing you need it to do,
  BEFORE you stop using the Windows machine that runs it today. "It opened" is not the same as "it
  printed the invoice".

IF IT DOES NOT WORK
  That is a normal outcome and it is not something you did wrong. Tell whoever set this computer up.
  There is often a replacement program that runs properly here, and it is usually free.

This computer is older than the programs you are asking it to pretend to run. Expect slow.
