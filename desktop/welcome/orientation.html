This computer runs Auros

It was set up for your organisation. You will not need to type any commands.

The button at the bottom left is the Start menu

Everything installed on this computer is in there. Start typing to search, the same as on Windows. Tapping the Windows key on the keyboard opens it too.

Your files are in Documents, Pictures, Downloads and Desktop

The same names as before. Open the folder icon on the taskbar, or press the Windows key and E. Double-click to open something — a single click only selects it.

Install programs from Discover

The shopping-bag icon on the taskbar. Search, then press Install. You never need to find a download on the internet, and you never need a command.

Updates happen by themselves, overnight

Nothing to click and nothing to remember. If an update ever goes wrong, this computer puts the previous version back on its own the next time it starts.

Your old Windows programs did not come across

Files, bookmarks, printers and Wi-Fi did. Programs did not, and cannot. You install the replacement here instead, usually free, from Discover.

Microsoft Office and Adobe programs do not run on this computer. Use Office on the web in your browser, or keep one Windows machine for it.
